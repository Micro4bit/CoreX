# Public data bundle

This repository deliberately omits DMR active-fault geometry, DMR rock-unit
geometry, and third-party publication PDFs because their redistribution terms
are unresolved or not recorded as suitable for this public repository.

The local research checkout can retain those inputs for permission-gated,
reproducible processing. A public clone remains useful for application source,
tests, provenance, the IHFC descriptive point layer and non-restricted
artefacts. Do not add omitted inputs unless written reuse permission is
recorded in the layer-provenance documentation.
