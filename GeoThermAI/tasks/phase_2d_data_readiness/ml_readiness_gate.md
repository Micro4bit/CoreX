# Predictive ML readiness gate — 2026-10-26

Decision: **NO-GO**.

Blocking conditions:

- only 47 surface-manifestation rows, with two northern coordinates withheld and 31 southern coordinates provisional;
- 18 groups are co-withholding assumptions, not expert-confirmed independent systems;
- no validated true-negative class and no approved positive–unlabeled sampling design;
- geology is partial/northern and contextual at 1:250,000;
- structural geometry is missing from one service and reuse-restricted for the active-fault file;
- terrain covers only five tiles;
- heat flow is sparse, repeated at coordinates, lacks measurement uncertainty and largely lacks depth;
- Landsat ST rasters were not acquired.

Minimum gate to reopen: resolve/withhold label conflicts under a signed data dictionary; expert-review independent groups; lock study area/background protocol; obtain permitted predictor coverage; preregister spatial/group validation and leakage controls; reserve an external geographic test. Baseline candidates after approval are geology-only, regularized logistic regression and one justified tree comparator, with satellite ablation only if real QA-cleared rasters exist.

No model was trained and no probability, heatmap, MW, LCOE or drilling-success result was produced.
