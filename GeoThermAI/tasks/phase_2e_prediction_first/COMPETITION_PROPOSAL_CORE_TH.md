# ร่างเนื้อหา Proposal หลัก — GeoThermAI (Prediction-first)

**สถานะ:** ร่างสำหรับประกอบแบบฟอร์มการแข่งขัน ยังไม่ใช่เอกสารสมัครฉบับสมบูรณ์และยังไม่ผ่านอาจารย์ที่ปรึกษา

## ชื่อโครงการ

**GeoThermAI: ระบบบูรณาการข้อมูลธรณีศาสตร์และปัญญาประดิษฐ์เพื่อคาดการณ์และจัดลำดับพื้นที่เป้าหมายในการสำรวจพลังงานความร้อนใต้พิภพของประเทศไทย**

## ปัญหาและความสำคัญ

การสำรวจแหล่งพลังงานความร้อนใต้พิภพต้องใช้ข้อมูลทางธรณีวิทยา ธรณีฟิสิกส์ ธรณีเคมี และข้อมูลความร้อนจากแหล่งต่าง ๆ ที่ต่างกันทั้งหน่วยวัด ความละเอียด ความครอบคลุมและความน่าเชื่อถือ การใช้ข้อมูลเพียงประเภทเดียวหรือการอ้างพื้นที่ที่ยังไม่ได้สำรวจว่าไม่มีทรัพยากรอาจทำให้การคัดกรองผิดพลาด GeoThermAI จึงเสนอกรอบการประเมินพื้นที่เพื่อช่วยจัดลำดับความสำคัญในการสำรวจเพิ่มเติม โดยยึดแบบจำลอง PFA และวิธี Geothermal Favorability ที่มีรายงานในงานวิจัยสากลมาพัฒนาให้เหมาะกับข้อจำกัดข้อมูลไทย

## วัตถุประสงค์

1. สร้างโครงสร้างข้อมูลที่ตรวจสอบต้นทาง หน่วย พิกัด ข้อจำกัดและสิทธิ์ใช้งานได้.
2. พัฒนาแบบจำลองเบื้องต้นสำหรับจัดลำดับ **ความเหมาะสมเชิงสัมพัทธ์** ของพื้นที่เป้าหมาย เมื่อชุดข้อมูลผ่านเกณฑ์ทางวิชาการ.
3. เปรียบเทียบแบบจำลองกับวิธี GIS/ธรณีวิทยาพื้นฐานและเทคนิคที่ซับซ้อนขึ้นโดยใช้ Spatial/Group Validation.
4. พัฒนาแผนที่สื่อสารหลักฐาน ความครอบคลุมของข้อมูล ความไม่แน่นอน และข้อจำกัดของผลทำนาย.

## วิธีดำเนินการ

**ระยะ A — วิจัยและเตรียมข้อมูล:** คัดเลือกพื้นที่ศึกษาตามความครอบคลุมและความชอบธรรมในการใช้ข้อมูล; ตรวจสอบ Positive Labels และการแยกระบบน้ำพุร้อนอิสระกับผู้เชี่ยวชาญ; ออกแบบตารางตัวแปรและมาตรฐานหน่วย; ตรวจสอบการรั่วไหลของข้อมูลระหว่างฝึกและทดสอบ.

**ระยะ B — การทดลองแบบจำลอง (เมื่อ Data Gate ผ่าน):** เปรียบเทียบ geology-only baseline, logistic regression ที่มี regularization และ tree model 1 วิธีภายใต้ Spatial/Group folds เดียวกัน; ทำ feature ablation และวิเคราะห์ความเสถียร.

**ระยะ C — ประเมินผลและพัฒนาต้นแบบ:** รายงานความสามารถในการจัดลำดับพื้นที่ ความไม่แน่นอน และพื้นที่ที่ยังมีข้อมูลไม่พอ; ออกแบบแผนที่ตอบคำถามว่า *ควรไปสำรวจที่ใดต่อ* พร้อมหลักฐานรองรับ.

## ความใหม่และความแตกต่างที่ตั้งใจพิสูจน์ (ไม่ใช่ข้อสรุปที่พิสูจน์แล้ว)

- ประยุกต์วิธี Prediction จากงานระดับสากลให้เข้ากับข้อมูลธรณีศาสตร์ไทยที่มีความไม่สมบูรณ์และมีข้อจำกัดด้านสิทธิ์เผยแพร่.
- แยก **คุณภาพ/ความครอบคลุมข้อมูล** ออกจาก **ความเหมาะสมของพื้นที่** อย่างชัดเจน.
- สร้างวิธีตรวจสอบกลุ่มตัวอย่างและขอบเขตการทำนายเพื่อป้องกันการรายงานความแม่นยำสูงเกินจริง.
- ทำให้ผลการประเมินย้อนกลับไปตรวจสอบหลักฐานและวิธีที่ใช้สร้างคะแนนได้.

## ผลผลิตที่คาดหวัง

- ระเบียบวิธีเตรียมและรวมข้อมูลหลายแหล่งที่ตรวจสอบได้.
- แผนที่ทดลองแสดงการจัดลำดับความเหมาะสม **เฉพาะเมื่อข้อมูลผ่านเกณฑ์** ไม่ใช่ผลยืนยันแหล่งกักเก็บ.
- รายงานเปรียบเทียบแบบจำลองและประเมินความไม่แน่นอน.
- ต้นแบบเครื่องมือสื่อสารผลเพื่อสนับสนุนการเลือกพื้นที่สำรวจขั้นถัดไป.

## การนำไปใช้และการต่อยอดธุรกิจ (สมมติฐานตลาด ไม่ใช่ยอดขายจริง)

ผู้ใช้เป้าหมาย ได้แก่หน่วยงานวิจัย/พลังงาน ผู้วางแผนสำรวจ และผู้พัฒนาโครงการพลังงาน ตัวแบบรายได้ที่อาจทดสอบได้คือการจัดทำรายงานคัดกรองพื้นที่และบริการวิเคราะห์ข้อมูลเชิงพื้นที่เฉพาะโครงการ จำเป็นต้องสัมภาษณ์ผู้ใช้เพื่อพิสูจน์มูลค่าและความเต็มใจจ่าย ไม่กล่าวอ้างว่าประหยัดงบได้เป็นจำนวนเงินโดยปราศจากการวัดผล.

## สถานะต้นแบบ ณ 26 ต.ค. 2569

Phase 2D ผ่านการทดสอบซอฟต์แวร์ GIS/Data Quality บางส่วน มีแผนที่หลักฐานและข้อมูลตรวจสอบต้นทาง แต่ **ยังไม่ฝึกโมเดล Prediction** และยังไม่มีหลักฐานความแม่นยำของ AI ขณะนี้งานวิจัยอยู่ในขั้นเตรียมต้นแบบทางวิธีวิจัยเพื่อฝึกและทดสอบในระยะถัดไป.
