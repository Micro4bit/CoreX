# แบบร่างหนังสือสอบถามสิทธิ์การใช้ข้อมูลกรมทรัพยากรธรณี

เรียน ผู้ดูแลข้อมูลภูมิสารสนเทศ กรมทรัพยากรธรณี

คณะผู้พัฒนาโครงการวิจัย GeoThermAI มีความประสงค์ศึกษาการบูรณาการข้อมูลธรณีวิทยาและโครงสร้างทางธรณีเพื่อประเมินความเหมาะสมเบื้องต้นของพื้นที่สำรวจพลังงานความร้อนใต้พิภพด้วยระบบสารสนเทศภูมิศาสตร์และการเรียนรู้ของเครื่อง โดยขณะนี้อยู่ในขั้นออกแบบงานวิจัย ยังมิได้ใช้ชุดข้อมูลที่มีข้อจำกัดสิทธิ์ในการฝึกโมเดล

ขอความอนุเคราะห์ชี้แจงเป็นลายลักษณ์อักษรเกี่ยวกับ (1) สิทธิ์ดาวน์โหลดและจัดเก็บข้อมูลดิบและ geometry ของข้อมูลกลุ่มรอยเลื่อนมีพลังและแผนที่ธรณีวิทยามาตราส่วน 1:250,000 (2) การใช้เพื่อวิจัยและฝึกโมเดล Machine Learning (3) เงื่อนไขการสร้างและเผยแพร่ข้อมูลอนุพันธ์ เช่น ระยะห่างจากรอยเลื่อน คะแนนพื้นที่และแผนที่ผลการประเมิน (4) การแสดงข้อมูลผ่านเว็บไซต์และการให้ดาวน์โหลด (5) ข้อจำกัดหากต่อยอดเชิงพาณิชย์ และ (6) รูปแบบการอ้างอิงที่กำหนด รวมทั้งข้อแตกต่างระหว่างเงื่อนไขในทะเบียนข้อมูลกับไฟล์ metadata ที่เกี่ยวข้อง

หากชุดข้อมูลที่ต้องการมีช่องทางติดต่อเจ้าของข้อมูลหรือข้อกำหนดการอนุญาตเฉพาะ โปรดแนะนำขั้นตอนการขออนุญาตอย่างเป็นทางการ

ขอแสดงความนับถือ
คณะผู้พัฒนาโครงการ GeoThermAI (กรอกชื่อผู้ประสานงาน/สังกัด/อีเมลก่อนส่ง)

**หมายเหตุ:** เป็นเพียงร่าง ยังไม่ได้ส่งคำขอหรือรับการอนุมัติจริง
